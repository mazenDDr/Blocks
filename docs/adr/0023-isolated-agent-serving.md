# ADR 0023: Isolated native agent turns in the local production registry

Status: accepted. Builds on ADR 0008 (native agents) and 0012 (immutable local serving).

1. **A bounded whole-graph adapter.** Register a completed agent run that reached native END using `__agent_graph__`; registration never trains or invokes a chat model. Accept only existing prompt, set-state and at most one chat-model node. Pure StateGraph workflows make zero model calls. LangGraph owns state channels, reducers, branches, joins, routes and bounded loops; the adapter calls the existing compiler and blocks rather than replacing them. Fixture/API/remote providers, retrieval, memory-policy/index nodes, tools, interrupts and thread-scoped fields are refused with stable errors. This release serves isolated turns, not conversation sessions. Unsupported graphs remain available in the research workspace.
2. **Declared bounds and contracts.** Require maxSteps ≤25, maxModelCalls ≤2, maxTokens ≤4096 and maxSeconds ≤30. Graphs have ≤16 nodes / ≤32 fields / 32 KiB JSON, defaults ≤8 KiB; templates have ≤2000 characters and ≤16 field references. Exactly the 1–4 text fields supplied in the source run become input fields; each request is one record, each value 1–2000 characters, total ≤8 KiB. A chat's text output field is the served response; a model-free workflow needs exactly one written text output field separate from inputs. Check native state after each superstep (≤64 KiB), rendered context before each call (≤16 KiB), and output type. Limits refuse outputs; they do not silently trim state, edit templates or shorten responses.
3. **Immutable identities and truthful reference.** Pin source graph/hash, completed final-state membership, source run configuration, input-only reference, native package/platform versions and execution-source hashes. Verify bytes and identities on every use, including cached pipelines. Local Ollama runs on port 11434 with think=false, max_tokens ≤128 and timeout_s ≤30; no downloads or key handling. Pin `/api/tags` model digest and `/api/version` at registration, recheck before/after execution. Earlier research runs did not record model digests; the manifest explicitly says the provider identity is pinned at registration, not retrospectively verified for the source run. Source inputs are not reference answers or a benchmark. Other serving families' pinned source files are untouched, so this release requires no domain retraining or dependency install.
4. **Native execution isolation.** Each execution gets a random run/thread ID, a temporary artifact store and fresh native in-memory saver. Seed only declared state defaults and validated request inputs. Never load a research checkpoint, copy a conversation, reuse a previous request's channels or write research memory/effects. The owning production runtime supplies deadline/cancellation checks; provider HTTP timeout is narrowed to the remaining deadline and the actual resolved setting is recorded. Check cancellation/budgets between native nodes/steps and before/after model calls; budget/recursion exhaustion is a failed serving request, even though the research worker can record a partial budget-stopped run as completed. An active provider call may finish before cancellation is observed; no hard process/token-stream interruption is claimed. Provider identity HTTP checks and observability lookups can also finish after a deadline; their result is discarded. Final request commit uses the existing cancellation check/transaction. Shared admission, idempotency, restart failure, immutable releases, route CAS and rollback semantics stay in force. Agent releases require maxBatch=1 and stateless mode; caller-supplied session IDs do not create native conversations.
5. **Recorded inspection and capture.** Return actual text predictions, execution/thread/source/graph/provider identities, state/event hashes and real provider-reported call usage/latency. Full state, native events and exact sent model contexts/segments are retained only under release captureInputs=true; captured contexts are copied to CAS and embedded in the committed trace. Capture off keeps hashes/usage metadata and the output text, not raw state/context/event bodies. Output text can itself quote an input; capture off is not redaction of generated responses. Temporary native stores are removed on success/failure. Captured values can be inspected through working Production controls without model calls. Registry/source manifests already contain source-run inputs through the established research contract; capture policy applies to new serving inputs. Aborted captured calls can leave CAS bytes without a successful request reference; broad retention/GC remains unimplemented.
6. **Warmup, replay and monitoring.** Candidate creation performs a real isolated warmup; its immutable recorded result is the monitoring reference. Replay requires captured inputs and performs a new native turn with a new execution ID; output may differ even on the same installed model. It does not mutate the source turn, route or session. Monitoring reads the immutable warmup and successful request traces without executing an LLM. Character-count KS comparisons are descriptive against a single reference; separately supplied strings give literal exact-string agreement, not semantic accuracy. Never turn a generated answer into inferred ground truth. Provider-token totals cover successful recorded serving calls only, excluding failures, warmup and replay. Cost and Ollama hardware placement/utilization are not measured; the traffic sampler covers its existing control/generator process scope, not the separate Ollama process.
7. **Editor and evidence.** `serving_agent` is a runnable picker example with SYNTHETIC teaching prompts and real local qwen3.5:2b; the historical `agent_*` generator prefix remains unchanged. Production lists compatible whole-agent candidates, shows pins/budgets, caps the release at one stateless turn, loads input-only references and displays exact captured contexts/state/events and replay caveats. Opening the registered source propagates its exact run identity to the agent trace; browser evidence compares against a genuinely later run. Native model-free tests verify reducers/parallel joins, isolation/idempotency/restart, contracts/refusals, capture, integrity, budgets and state growth without scripted model output. Separate live tests verify actual Ollama contexts/usage/digest refusal and capture. The HTTP journey and installed-Chrome verification exercise the real serving flow.

Verification also reproduced an existing CNN-worker cancellation race: the control writer can mark a run cancelling between the worker’s status read/write. The worker now uses its existing guarded transition rather than performing that separate check. Strict store transitions and checkpoint serialization stay unchanged; a new native SQLite interleaving regression verifies actual cancellation/partial-checkpoint evidence. No existing pinned serving-family source identity includes the changed cancellation helper.

Remaining scope: persistent conversations with atomic checkpoint commits and isolation; pinned retrieval/index/source or memory-policy dependencies; effects/interrupt approval semantics; structured/multiple model nodes, streaming and external providers; Keras/JAX and other serving families; broader measured workloads. Shared-token authentication remains separate from caller-declared identity keys. Remote/distributed deployment and hardware claims require real infrastructure and verification.
