# ADR 0014 — Native domain checkpoints, epoch continuation and local inference

Status: implemented within the bounds below, 2026-10-04. Extends ADR 0011; does not replace ADR 0012's tabular production adapter.

Vision TinyFCN, NLP packed BiGRU and speech CTC runs previously persisted only evaluation summaries. A completed domain run now also records its actual state dictionary and a content-addressed model manifest so inference and continuation do not need the live Python object.

- **Native state, not a whole Python module.** `torch.save` writes model weights, Adam state, completed epoch, learning curve, PyTorch RNG and the dedicated shuffle-generator state. Speech also stores training-only per-mel mean/std. Loads explicitly use `torch.load(..., map_location="cpu", weights_only=True)`; no allowlisting of arbitrary globals, uploaded module/pickle, or artifact path input. Internal run/node membership, completed source run, size and SHA checks precede loading. A manifest pins native library/Python versions and implementation file hashes. Nonfinite weights cannot become a saved model.
- **Exact completed-epoch continuation.** A child graph/run declares `resume_model_id` and a larger total `epochs`. Prepared tensors and labels, source/geometry, resolved model/optimizer/split settings, fitted tokenizer and CPU thread count must agree. State restoration includes optimizer and shuffle/RNG state. Tests compare resumed 2→4 epochs against uninterrupted four epochs bit-for-bit for weights, optimizer tensors, RNG and curves for all three families. This proof is for the pinned CPU environment; no mid-batch/failed/cancelled-run resume or GPU/cross-version exactness is claimed. Domain cancellation remains between nodes, so the active training node finishes first.
- **Tokenizer identity survives native tie-breaking.** NLP's tokenizer may be rebuilt differently even from the same corpus. Continuation explicitly uses `fitted_model_id` on the tokenizer node to reload the authoritative saved tokenizer JSON. Corpus identity and resolved tokenizer/split settings are checked; the tagger's prepared-data signature verifies actual IDs/labels/word boundaries and vocabulary before state restoration. Inference encodes original text with that exact tokenizer; complete-word first-subword readout and source character offsets remain visible. Invalid predicted IOB2 sequences are reported, not silently corrected.
- **Pinned inference boundary.** Vision accepts only RGB PNG at the training model's post-geometry size (at most 512×512); it performs the saved numerical normalization and FCN forward pass. Resize/crop/random flip are explicit upstream preparation, never silently applied to requests. Masks and connected-component boxes are native predictions, with derived-detection meaning. Speech accepts finite normalized PCM, declared rate, 1–4 equal-length channels and at most 32,000 samples/channel; native mean-to-mono, pinned framing/mel features and saved train-only normalization precede CTC/greedy decoding. Feature frames cap at 4096; clips incompatible with padding/windows are refused. Greedy onset times are not forced alignments. NLP accepts nonempty text up to 4000 characters, with saved truncation/mask/alignment semantics.
- **Read-only local inference/export.** `/api/domain/models` exposes recorded models, including unavailable identities with specific errors. `/api/domain/models/{id}` returns the pinned manifest; `/checkpoint` downloads native state; `/example` reads an explicitly labelled recorded SYNTHETIC held-out input; `/predict` performs actual native inference with exact model/run/graph/node/source/checkpoint provenance. Inference never rereads sources, refits, trains or appends run events/artifacts. Two concurrent requests, batches of 1–4, decoded JSON up to 1.5 MB; these are local admission/input bounds, not a native wall-time guarantee. No multi-user authentication or remote deployment is implied.
- **Editor continuity.** Domain workspace has working native checkpoint/manifest links, explicit draft continuation preparation, recorded validation-input loading and editable inference JSON. Vision masks, NLP word/span/label tables and speech decoded text/onsets are readable; complete prediction/provenance remains expandable. Continue edits the draft and requires Run to create a new run; the parent stays immutable.

Native reference: [PyTorch serialization semantics](https://docs.pytorch.org/docs/stable/notes/serialization) and [saving/loading a general checkpoint](https://docs.pytorch.org/tutorials/beginner/saving_loading_models). Installed native versions and persisted state are authoritative. Restricted weights-only loading is one part of the internal-artifact boundary, not a sandbox for arbitrary uploaded tensors.

Remaining: intermediate checkpoint cadence, mid-node pause/cancel/recovery, portable import with explicit environment migration, raw-image geometry pipelines, general datasets/pretrained architectures, GPU execution, and domain integration into registry/release/traffic/monitoring. The tabular production adapter stays unchanged. Model/optimizer exports may reveal learned information and the manifest identifies local source paths; choose where to share exported artifacts.
