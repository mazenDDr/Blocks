# ADR 0020 — Unsupervised models in the local production registry

Status: implemented within the bounds below, 2026-10-04. Extends ADR 0012 and the unsupervised workflows of ADR 0009.

- **Capture without changing the tabular adapter.** After a tabular run, `production/unsup_adapter.capture` records an `unsup_pipeline` manifest for every unsupervised model output, or an explicit `unsup_refusal`. The manifest holds features, the scaled flag, parameters, fitted rows, source node, evaluation summaries, environment and implementation hashes, the hash-verified native model pickle and a frozen reference of up to 2,000 fitted rows. The code lives outside `production/pipeline.py`, so the tabular adapter identity (ADR 0012) is unchanged and previously registered tabular versions keep serving; a test pins that file set.
- **What is served.** Only estimators that natively map new points are served: k-means (nearest centroid, distances), Gaussian mixture (component, responsibilities, log density) and PCA (component scores, reconstruction error). DBSCAN and t-SNE get `E_PIPELINE_UNSUPPORTED` ("cannot map new points"). Requests carry exactly the raw numeric feature columns. If a fitted transform sits between the source and the estimator, capture refuses rather than approximating it. Only selection, profiling, duplicate handling, row drops and the split may sit upstream. Served outputs equal the run's own fitted scaler and estimator (tests compare predictions, responsibilities, projections and reconstruction errors).
- **No accuracy for clusters.** Optional external labels (strings or integers, booleans refused) give permutation-invariant adjusted Rand index and normalized mutual information, never accuracy (A55). PCA refuses labels; monitoring reports its label-free reconstruction error next to the fitted rows' error. Feature drift (KS) and cluster-assignment frequency or PC1 drift compare against the frozen fitted rows, which are labelled in-sample.
- **Editor.** Production lists "kmeans / gmm / pca (scikit-learn, unsupervised)" candidates with a pinned-estimator panel, **Load fitted rows**, and label guidance per method.

Remaining: fitted preprocessing before an unsupervised estimator, DBSCAN/t-SNE out-of-sample mapping (not native), and agent or Keras/JAX serving.
