# ADR 0017 — Domain models in the local production registry

Status: implemented within the bounds below, 2026-10-04. Extends ADR 0012 (local registry/serving) with the ADR 0014 domain checkpoints.

ADR 0012 served only native scikit-learn tabular pipelines. Vision, NLP and speech models already persist a verified native state dictionary and a pinned manifest (architecture, preprocessing, tokenizer/labels/alphabet, environment and implementation hashes; ADR 0014). `python/production/domain_adapter.py` makes them a second registry family without changing the shared release, routing, admission, trace or lifecycle records.

- **Registration.** `POST /api/production/versions` with a completed run and node registers that node's recorded internal `domain_model` when the node has no tabular pipeline. Registration loads the native model and requires its recorded held-out example; it never trains. The version records `adapter: domain`, family, model id and a manifest summary: run, node, graph, checkpoint, epochs, parent model, source, environment, implementation, labels/classes, tokenizer and input contract.
- **Serving.** A release warms up on the recorded SYNTHETIC held-out example. `maxBatch` must be ≤ 4, and requests carry 1–4 records within 1.5 MB, matching `/api/domain/models/{id}/predict`. The model is rebuilt once per version from the strict state dictionary. The manifest, checkpoint hash, environment and implementation are re-verified on every use, so a changed implementation refuses serving (409). Forward passes are serialized per loaded model. Input errors from the native preprocessing become `E_REQUEST_SCHEMA` traces. Domain timing measures preprocessing, forward pass and decoding together and says so. Routes, idempotency, cancellation, deadlines, capture policy, replay, rollback and traffic are the ADR 0012 mechanisms unchanged.
- **Labels and quality.** Ground truth is per record: NLP takes one IOB2 label per original word from the pinned label set, speech a reference transcript, vision an H×W integer class mask. Quality uses native conventions: NLP word accuracy plus seqeval span F1 (reported as undefined when neither labels nor predictions contain a span, rather than seqeval's 0), speech corpus CER/WER, vision confusion-matrix pixel accuracy and mean IoU/Dice. Recorded labels are immutable.
- **Drift.** Captured inputs are summarised by descriptive scalars (NLP characters/words, speech duration/RMS, vision intensity mean/std) and compared by KS with the pinned model's own held-out example. Prediction frequencies (word labels, decoded characters, mask pixel classes) use total variation against that example's predictions. The reference is a single recorded example, so the evidence is weak; the response says so. Drift never triggers training or rollback.
- **Editor.** Production ▸ Registry lists domain candidates by family. The version panel shows the pinned model, checkpoint, epochs, tokenizer, classes and environment instead of tabular transform steps. Release caps maxBatch at 4. Requests loads the held-out example and explains each family's label format. Monitoring shows the family metrics.

Remaining: no CNN (model-graph), agent, RL, unsupervised or Keras/JAX registry adapters; no larger monitoring reference for domain models; no GPU, remote deployment or multi-replica serving (ADR 0012 limits apply).
